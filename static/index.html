VIDEO WORKSPACE

让声音、字幕与视频创作，汇成可复用的工作流。

批量转写录音，提取并翻译字幕，生成自然语音，再完成视频创作与交付。

MCP 服务器运行在此端点，使用 Bearer Token 认证。

首次设置

运行 vwactl init 后，将一次性令牌和新密码填入此处。

02

管理员登录

登录后，此设备将保持登录 30 天；退出或重置密码会立即失效。

或

当前浏览器或连接不支持 Passkey；远程访问请使用 HTTPS。

使用 MADLAD-400-3B 翻译纯文本或 SRT 字幕；英文与俄语排在语言列表前两位。

04
